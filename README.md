# R Programming and Statistical Analysis

R programming examples and applied statistical projects by Derrick Achanga.

## Portfolio projects

### [UK Income Inequality Exploratory Analysis](projects/uk-income-analysis/README.md)

An exploratory analysis of 11 annual UK observations (2006–2016), with cleaned R code, descriptive tables, visualisations, a multiple-regression model and an independent numerical verification against the original R report. The README documents the small-sample limitations and input-data restrictions.

Original R programming examples elsewhere in this repository are retained.

### [Two-Asset Diversification Analysis](projects/two-asset-diversification/README.md)

A self-contained exercise with hypothetical inputs, a tested Python implementation, a reviewed R counterpart, a 22-row results table, an SVG chart and explicit validation notes. Explores correlation and long-only minimum-variance allocations.
